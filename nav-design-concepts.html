Desktop + Mobile

Navigation Redesign — 4 Concepts

Community → Channel → Space → Project is 4 levels deep. No bottom nav on mobile. Projects have no direct chat access. These concepts fix all three on both platforms.

⌘
A — Command Palette + Recents
⌘K global jump + automatic Recents strip. On mobile: floating search button + full-screen search panel.
Recommended
⊞
B — Dual Rail Sidebar
Community icon rail + context panel on desktop. On mobile the rail becomes a bottom tab bar — the hierarchy is one tap away.
Alternative
💬
C — Project Chat Panel
Chat tab embedded inside every project. On mobile: a bottom sheet that slides up from a chat button.
Additive
📱
Mobile — Bottom Nav Bar
A persistent 5-tab bottom nav replaces the hamburger drawer on mobile. The highest-impact mobile-only change.
Mobile-first

🔥 The Problems

  • 4 clicks minimum to reach a project from scratch
  • Mobile: hamburger drawer is fine for a menu, bad for a work app
  • Projects and their Space chat are disconnected — different URL trees
  • Shortcuts need manual setup — won't help new or casual users

✅ Best Combination to Ship

  • A — Command palette (works on both desktop + mobile)
  • C — Project chat panel (biggest missing feature)
  • Mobile tab — Bottom nav bar (standalone mobile win, low risk)
  • All three can be shipped independently — no sidebar refactor needed

📱 Why Bottom Nav First

  • Current hamburger drawer requires 2 taps minimum to navigate anywhere
  • Bottom nav = 1 tap to any top-level section, always visible, always reachable with thumb
  • Standard pattern in Linear, Notion, Slack, GitHub, Figma mobile apps
  • Works great with Concept A (floating search) and C (chat bottom sheet)

🛠 What to Build

  • 1 New BottomNav component — block md:hidden (show only on mobile)
  • 2 5 tabs: Home, Projects, Chat (with unread badge), Community, Profile
  • 3 Keep the existing sidebar drawer but auto-hide on mobile when bottom nav is present
  • 4 Add pb-14 padding to dashboard layout on mobile to avoid content hiding behind nav
  • 5 Persist active tab in Jotai or URL state

⚡ 5-Tab Structure

  • 🏠 Home — dashboard / activity feed
  • 📁 Projects — all your active projects across communities
  • 💬 Chat — DMs + space chats, with global unread badge
  • 🌐 Community — browse/switch communities, channels
  • 👤 Profile — your profile, settings, sign-out
